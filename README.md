## Selected Work

> A few things I've built while exploring different layers of software.

<br/>

### 01 — Socket Chat

**Real-time communication from the ground up.**

A terminal-based chat system built around C++ socket programming and client-server communication.

`C++` · `TCP/IP` · `Sockets` · `Networking`

<br/>

### 02 — Hotel Manager

**A modern full-stack management system.**

A Next.js application exploring real-time updates, Supabase integration, WebSockets and automated testing.

`Next.js` · `TypeScript` · `Supabase` · `WebSockets`

<br/>

**Breaking language barriers in real time.**

`Python` · `AI` · `Speech Processing` · `Real-Time`

<br/>

### 04 — Network File Sharing

`C++` · `Networking` · `File Systems`
